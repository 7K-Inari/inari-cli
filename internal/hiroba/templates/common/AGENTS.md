# Hiroba app agent guide

Use Conventional Commits and independently versioned components. Keep canonical observability in observability/ and regenerate chart/pack outputs with the workflow library. Keep releaseComponents synchronized with selected component paths; artifact-bound smoke inherits its target identity. Preserve the explicit archetype: stack sources always retain complete tests/stack install+upgrade declarations and non-stack sources never add them. All external actions and reusable workflows use full commit SHAs with version comments. Never add classic Helm indexes, UI Release assets, mutable release callers, or real-environment smoke execution. Use only public Inari SDK contracts.
