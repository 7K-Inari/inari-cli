# Contributing

Open a pull request with Conventional Commits. All applicable workflow lanes must pass, including negative generated-output checks. Do not commit secrets, customer data, generated diagnostics, or registry credentials.

Read the [Hiroba governance](https://github.com/7K-Hiroba/community/blob/main/GOVERNANCE.md), [onboarding checklist](https://github.com/7K-Hiroba/community/blob/main/docs/governance/onboarding.md), and [trust-tier policy](https://github.com/7K-Hiroba/community/blob/main/docs/governance/trust-tiers.md). External contributions are currently paused while CLA coverage is reviewed; do not merge an external PR until the organization enables that process. Visit the [Hiroba organization profile](https://github.com/7K-Hiroba) for community context.
